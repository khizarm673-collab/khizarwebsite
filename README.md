# BCHVision

Interactive dashboard for BCH code construction, encoding, error injection and decoding.
Pure HTML/CSS/JS, no build step, no dependencies.

* `bch.js` : GF(2^m) arithmetic, cyclotomic cosets, minimal polynomials, generator g(x), systematic encoder, syndrome + Berlekamp–Massey + Chien decoder, exact d_min search.
* `index.html` : the dashboard.
